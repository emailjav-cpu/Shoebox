# Logo

Drop a single logo file here and the renderer picks it up automatically for the
post footer, replacing the `javierdiaz.design` wordmark.

- **Formats:** `.svg` (preferred), `.png`, `.jpg`, `.webp`
- **Rendered at:** 34px tall, width automatic
- **Colour:** near-black `#17150F` or muted `#6B655A` on the `#FAF9F5` paper.
  Not pure black, and not ochre — the accent is spoken for.
- Give a PNG a transparent background and at least 3x the final height (~100px)
  so it stays sharp.

If more than one image file is here, the first by filename wins. Override per
render with `--logo path/to/file`.
